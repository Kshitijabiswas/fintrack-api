# FinTrack

FinTrack is a simple and efficient personal finance tracking application that helps users manage expenses, monitor income, and gain insights into their financial habits. It is designed to be lightweight, modular, and easy to integrate with any frontend or mobile client.

---

## Features

- Track daily expenses with categories
- Manage income sources
- Set and monitor monthly budgets
- View spending summaries and insights
- REST API for external integrations
- Clean and modular backend architecture
- Optional JWT authentication
- Logback-based logging with daily rotation

---

## Tech Stack

- Java (Spring Boot)
- PostgreSQL / H2 (dev)
- Maven
- Logback
- Docker-ready
